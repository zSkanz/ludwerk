# Coming from a similar API

The migration guide is part of the manual now, so it is kept beside the pages
it links to and stays in step with the engine:

- [The migration guide](manual/migrating/migration.md) — what transfers, what
  is spelled differently, and habit by habit what to write instead.
- [Every deliberate divergence](manual/migrating/divergences.md) — the full
  list of renamed and removed names, with the reason for each.
- [What is not here](manual/migrating/not-here.md) — the gaps, each with its
  state.

The manual is also published as a site with the API reference: run
`scripts/docs.ps1` on Windows or `./scripts/docs.sh` elsewhere to build it and
open it.
